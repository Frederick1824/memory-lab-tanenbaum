# Memory Lab

SPA educativa para una exposición universitaria sobre gestión de memoria en Sistemas Operativos. Esta primera etapa incluye la identidad visual, navegación, portada, módulos temáticos y placeholders para futuras simulaciones.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Para crear una versión optimizada:

```bash
npm run build
npm run preview
```

## Estructura

- `src/components`: piezas visuales reutilizables.
- `src/pages`: páginas y rutas principales.
- `src/data`: contenido centralizado de los módulos.
- `src/types`: contratos TypeScript compartidos.
